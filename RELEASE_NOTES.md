# Release notes: v1.0.0-candidate

Release date: 30 July 2026.

## Scope

This is the first unified anonymous candidate release of *Exact Low-Length
Recht–Ré Inequalities*. It contains exactly one manuscript and consolidates
the four- and five-factor exact results, a general balanced-seed continuation
theorem, new six-factor balanced families, and the exact one-epoch
bias--mean-square reversal.

## Acceptance evidence

- complete fresh-extraction replay with final result
  `PUBLICATION-CANDIDATE REPLAY: PASS`;
- 2,312 exact six-factor coefficient identities;
- four exact full-matrix FLINT PSD certificates;
- independent semantic reconstruction of the four- and five-factor encodings;
- ordinary, semantic, coordinate-order, indefinite-PSD, and omitted-path
  negative controls;
- package-wide anonymous single-paper, manifest, citation, and verifier-safety
  gates; and
- final mathematical and package audits.

The release carries six files: the exact tagged-tree ZIP, anonymous PDF,
complete replay transcript, outer machine-readable release certificate,
certificate SHA-256 sidecar, and `SHA256SUMS.txt`. GitHub and the manually
created Zenodo record at exact version DOI `10.5281/zenodo.21709239` carry
byte-identical copies. The all-versions concept DOI is
`10.5281/zenodo.21709238`; `PUBLICATION_READBACK.json` on `main` records the
post-publication identifiers, timestamps, hashes, attestations, and
unauthenticated verification.

## Assurance boundary

This is an unrefereed computer-assisted candidate, not a formally verified or
peer-reviewed theorem. Exact replay establishes that the packaged programs
accept the bound certificates and reject the bundled mutations. It does not
establish literature priority, external expert acceptance, independent
reproduction, or correctness beyond the documented semantic and certificate
boundaries.
